# 뉴스맵 인터랙션 프로토타입

`main`(d866f37)의 화면을 기준으로, 뉴스맵·뉴스 상세·레포트를 **한 화면 안에서 이어지는 흐름**으로 다시 설계한 Claude Design 프로토타입이다.
`src/`의 앱 코드는 바꾸지 않았다. 이 폴더는 디자인 참고 자료이며 빌드·배포 대상이 아니다.

## 파일

| 파일 | 내용 |
|---|---|
| `Main.dc.html` | 01 검색창 |
| `KeywordMap.dc.html` | 02 키워드 맵 |
| `NewsMap.dc.html` | 03 뉴스맵 · 상세 · 레포트 (이번 작업의 본체) |
| `canvas.json` | 캔버스 배치 정보 |

`.dc.html`은 Claude Design 런타임(`support.js`)에서 동작하는 형식이라 브라우저에서 파일만 열면 렌더링되지 않는다. 확인은 Claude Design 캔버스에서 한다. 캔버스는 비공개이며, 공유가 필요하면 작성자에게 요청한다.

## 뉴스맵 조작

| 조작 | 동작 |
|---|---|
| 클릭 | 카드 선택·해제 (리포트 근거) |
| 더블클릭 | 그 카드를 화면 가운데로 이동 |
| Space + 클릭 (키보드: Shift+Enter) | 그 카드 기준 검색 — 처음이면 하위 뉴스 펼치기, 이미 펼쳤으면 재검색 |
| 휠 | 확대·축소 (트리 전체 크기에 맞춰 범위 제한) |
| 끌기 | 화면 이동 (트리 범위 안) |
| 상세 버튼 | 카드로 확대 + 오른쪽 상세 패널 (Esc로 닫기) |
| 선택 바 · 상세의 리포트 버튼 | 선택한 카드들을 근거로 리포트 패널 (Esc로 닫기) |

## 설계 요점

- **궤도형 배치:** 하위 단계로 갈수록 카드·궤도가 0.6배로 작아지고 카메라는 그만큼 확대한다. 가운데 카드는 단계와 관계없이 같은 크기로 보인다.
- **자동 정렬:** 물리 시뮬레이션으로 겹침을 푼다. 다른 가지끼리 부딪히면 가지 전체를 밀어 카드가 섞이지 않게 한다. 연결선은 직선.
- **궤도 표현:** 가운데 카드에서 가까운 궤도일수록 진하고 빠르게 회전한다. 기본값은 3궤도까지 회전 (Tweaks: `orbitRotating`, `orbitSpeed`).
- **미니맵:** 오른쪽 아래. 현재 화면 영역 표시, 누르면 그 위치로 이동.
- **레포트:** 근거 카드에 번호를 붙이고 나머지는 흐리게 한다. 근거를 빼거나 더하면 다시 생성한다.

## 데이터

- 중앙 뉴스와 1단계 연관 뉴스 4건은 `src/data/mockData.ts`의 목업 기사다.
- 하위 뉴스·재검색 결과·리포트 본문·차트는 모두 샘플이며 화면에 `[샘플 기사]` 등으로 표시했다.

## 현재 백엔드로 동작 가능한지 (2026-09-27 확인)

기준: capstone-backend `a287f2e`, capstone-deploy `e6f0f82`, econmind-docs `dfb5b1c`.

| 기능 | 판정 | 근거 |
|---|---|---|
| 키워드 → 검색 | 가능 | `GET /keywords/recommended`, `GET /news/search` |
| 뉴스맵 카드 | 일부 | `/related` 응답에 출처·발행 시각이 없어 카드마다 `/source` 추가 호출 필요 |
| 하위 뉴스 펼치기 (여러 단계) | 불가 | `_related_articles`가 최초 검색어의 같은 결과 묶음을 돌려준다 (`app/api/v1/news.py`). 깊이 내려가도 형제·부모 기사가 다시 나온다. `/graph`의 `depth`는 사용되지 않는다 |
| 재검색 (다른 결과) | 불가 | `/related`에 제외 ID·페이지·오프셋 파라미터가 없다 |
| 상세 패널 | 가능 | `GET /news/{id}/source` (정치·사회 기사는 404, 썸네일은 빈 값일 수 있음) |
| 여러 기사 근거 리포트 | 일부 | 본문 추출은 첫 기사 1건만(Diffbot), 나머지는 설명문 5건까지만 프롬프트에 들어간다 (`reports.py`, `report_generator.py`) |
| 종목 방향 카드 · 차트 | 불가 | `ReportResponse`에 방향·입장·시세 필드가 없다. 종목별 행동은 `/strategies`의 `action`만 있다 |
| 생성 단계 표시 | 불가 | `POST /reports`는 동기 처리 후 `completed`만 반환한다 |

또한 `docs/03-current-state.md`의 2026-09-19 결정으로 **뉴스맵의 관계 기반 선정·다단계 확장·동적 시각화는 보류** 상태다. 이 프로토타입을 실제로 구현하려면 팀이 보류를 해제해야 한다.

### 필요한 백엔드 작업 (최소)

1. 카드 기준 연관 뉴스 조회와 `exclude_ids` 지원 (펼치기·재검색)
2. 선택 기사 여러 건의 본문 추출 (건수 상한, 실패 건 건너뛰기)
3. 리포트 응답에 종목별 방향·전략 입장 추가, 또는 `/strategies` 결과 합치기
4. 리포트 비동기화와 진행 단계 조회
